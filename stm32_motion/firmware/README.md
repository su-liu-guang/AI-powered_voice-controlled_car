# STM32F103 小车轮速调试固件

日期：2026-10-24。适用芯片：STM32F103C8，8MHz 外部晶振、72MHz 系统时钟。

| 动作 | 左侧 PWM | 右侧 PWM |
| --- | --- | --- |
| 前进直行 | +80% | +80% |
| 后退直行 | -70% | -70% |
| 左转 / 前进+左转 | +56% | +70% |
| 右转 / 前进+右转 | +70% | +56% |
| 后退+左转 | -70% | -56% |
| 后退+右转 | -56% | -70% |
| 停止 / 矛盾动作 | 0 | 0 |

LED 位不影响运动。UART 为 USART1、115200 8N1，接收引脚 PA10；电机使用 TIM4 PB6～PB9。

## 烧录

- `firmware.bin`：写入地址 `0x08000000`，文件大小 3340 字节。
- `firmware.hex`：Intel HEX 格式，自带地址信息。
- BOOT0、串口隔离与下载方式详见[工程说明](../README.md)。烧录后先悬空测试方向、左右转和停止。

## 验证状态

PlatformIO release 编译通过，Flash 3340 / 65536 字节，RAM 1696 / 20480 字节。
ARM 模拟逻辑测试通过，覆盖全部 32 种有效状态、保留位拒绝、LED 不影响轮速、CRC 与串口队列恢复。
本固件尚未烧录、未验证实际轮速与电机能否在 56% PWM 下转动。非零 PWM 不保证电机转动。

`SHA256SUMS.txt` 校验发布文件；`manifest.json` 记录构建配置和全部源码文件的 SHA-256。
